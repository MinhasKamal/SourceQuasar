Instructions

Welcome to the Full Multi-Language IDE! Create multiple files and your work is safely saved in local storage.

Keyboard Shortcuts

  • Tab / Shift+Tab Smart Indent
  • Ctrl + / Toggle Comment
  • Ctrl + F Find / Search
  • Alt + ↑ / ↓ Move Line Up/Down
  • Alt + Drag Column / Rectangular Selection

Power Features

  • Smart Indentation: Auto-sniffs indent rules on load (Tabs vs Spaces, Size).
  • Multi-Language: Auto-loads syntax highlighting based on file extension (.py, .js, .cpp).
  • Super Linter: Extracts and lints JS and CSS embedded directly inside HTML files.
  • Diff Gutter: Tracks un-staged edits natively.
  • Minimap: Click to scroll, drags proportionately.
  • Gutter Bookmarks: Click a line number to bookmark it and highlight it on the scrollbar.
