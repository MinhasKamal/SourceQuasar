Instructions

You can write, format, and manage multiple code files across C/C++, Python, Java, JavaScript, SQL, PHP, HTML, CSS, and more.

As there are no servers, your data is saved in the local storage and never leaves your device. So, it is private, safe, and free for all kinds of usage.

Keyboard Shortcuts

  • Tab / Shift+Tab Smart Indent
  • Ctrl + / Toggle Comment
  • Ctrl + F Find / Search
  • Ctrl + S Save Document
  • Alt + ↑ / ↓ Move Line Up/Down
  • Ctrl + Z / Y Undo / Redo
  • Ctrl + Click Multi Cursor
  • Alt + Select Vertical or Column Select and Edit

Power Features

  • Smart Indentation: The editor automatically sniffs your code on load to detect indentation: 2-space, 4-space, or Tab. You can also override this.
  • Code Beautifier: Click "Format Code" to clean up messy HTML, CSS, and JS structure following your preferred indentation.
  • Multi-Language Highlighting & Linting: Dynamically detects file extensions and loads syntax modes and linters.
  • Auto-Save: All files are silently saved to your browser's local storage as you type. They will be restored even after you restart your device.
